# 🌍 TripCraft AI

AI-powered travel planner built using Streamlit and Gemini API.

## 🚀 Features
- Generate day-wise travel itinerary
- Clean card-based UI
- PDF download
- Regenerate option

## 💻 Tech Stack
- Python
- Streamlit
- Gemini API
- ReportLab

## 🛠 Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
